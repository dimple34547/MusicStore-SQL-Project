# Music Store SQL Analysis Project

## 📌 Project Overview

This project is based on a Music Store database. The objective is to analyze customer behavior, sales, artists, albums, genres, invoices, and employee information using SQL queries.

## 🛠️ Tools Used

* PostgreSQL
* pgAdmin 4
* SQL
* GitHub

## 📊 SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* JOIN
* Subqueries
* Common Table Expressions (CTEs)
* Aggregate Functions
* Window Functions
* ROW_NUMBER()
* RANK()
* SUM()
* COUNT()
* AVG()
* COALESCE()
* CASE Statements
