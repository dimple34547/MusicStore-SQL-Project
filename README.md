\# Music Store SQL Analysis Project



\## 📌 Project Overview



This project is based on a Music Store database. The objective is to analyze customer behavior, sales, artists, albums, genres, invoices, and employee information using SQL queries.



The project demonstrates the use of SQL concepts such as:



\* SELECT

\* WHERE

\* GROUP BY

\* ORDER BY

\* JOIN

\* Subqueries

\* Common Table Expressions (CTEs)

\* Aggregate Functions

\* Window Functions

\* ROW\_NUMBER()

\* RANK()

\* SUM()

\* COUNT()

\* AVG()

\* COALESCE()

\* CASE statements

\## 📊 Key SQL Concepts Covered



\### Aggregate Functions



Used functions such as `SUM()`, `COUNT()` and `AVG()` to calculate totals, counts and averages.



\### JOIN



Used different types of joins to combine data from multiple tables.



\### Subqueries



Used subqueries to solve questions involving comparisons and filtering based on other query results.



\### Common Table Expressions (CTE)



Used CTEs to make complex queries easier to understand and organize.



\### Window Functions



Used window functions such as `ROW\_NUMBER()` and `RANK()` for ranking and analytical calculations.



\### COALESCE



Used `COALESCE()` to handle NULL values and provide alternative values when required.
